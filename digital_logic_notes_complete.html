LECTURE 18

Sequential Circuits & Latches

1. Combinational vs Sequential Circuits
Combinational Circuit
Output depends only on present inputs. No memory. No feedback.
  • Same inputs → always same output
  • Examples: AND gate, adder, multiplexer, decoder
  • Described by Boolean function
  • No clock required
Sequential Circuit
Output depends on present inputs and past history (state). Has memory and feedback.
  • Same inputs may give different outputs depending on state
  • Examples: registers, counters, FSMs
  • Described by state table / state diagram
  • Usually clocked
General Sequential Circuit — Combinational Logic + Memory with Feedback
2. Bistable Element — The Concept of Memory

A bistable element has two stable states: 0 and 1. It stays in either state indefinitely until forced to change.

  • Two cross-coupled inverters = simplest bistable
  • Output Q̄ feeds back to Q's input and vice versa
  • Once set to a state, it holds that state — this is memory
  • No inputs to control it → no useful memory device alone
  • Adding control inputs → SR Latch
Bistable — Cross-Coupled Inverters
3. SR Latch Using NOR Gates — Gate-Level Circuit
The SR (Set-Reset) latch is built from two cross-coupled NOR gates. S=Set forces Q=1; R=Reset forces Q=0.

Why S=R=1 is Forbidden: Both NOR gates output 0, making Q=Q̄=0. This violates the complementary output requirement. When both return to 0, the final state is unpredictable (race condition).
Q(t+1) = S + R̄·Q   (with constraint S·R = 0)
How NOR Latch Works:
  • S=1,R=0: NOR1 output forced to 0 (since any input 1 → NOR=0). Q̄=0 → NOR2: both inputs 0 → Q=1 ✓
  • S=0,R=1: NOR2 output forced to 0. Q=0 → NOR1: both inputs 0 → Q̄=1 ✓
  • S=0,R=0: Each gate output depends only on the other's output → holds previous state

Key Difference from NOR Latch:
  • NOR latch: HIGH (1) is active → apply 1 to set/reset

  • R̄=0 forces NAND2 output=1 (Q̄=1, then Q=0, Reset)

LECTURE 19

Introduction to Flip-Flops & The D Flip-Flop

1. The Problem with Latches — Why Flip-Flops are Needed
Transparency Problem: A latch is transparent — while EN=1, output Q follows input D continuously. Any glitch or noise on input gets passed to output.
  • If EN is HIGH for a long time, multiple state changes possible
  • In digital systems, we want exactly ONE state change per clock cycle
  • Solution: Edge-triggered flip-flop — captures input ONLY at the clock edge (transition moment)
  • Edge is instantaneous — practically no window for multiple changes
Latch vs Flip-Flop — Transparency Problem
2. Level-Triggered vs Edge-Triggered
Level-Triggered (Latch)
  • Active whenever enable level is HIGH (or LOW for active-low)
  • Transparent during the entire enable period
  • Positive level-triggered: active while CLK=1
  • Negative level-triggered: active while CLK=0
Edge-Triggered (Flip-Flop)
  • Active only at the clock transition (edge)
  • Positive edge-triggered (↑): samples at 0→1 transition
  • Negative edge-triggered (↓): samples at 1→0 transition
  • Negative edge shown by bubble (∘) on clock input
Level-Triggered vs Edge-Triggered Timing
3. D Latch — Gate-Level Implementation

The D (Data) latch solves the SR forbidden state by connecting S̄ = D and R̄ = D̄. This ensures S and R are always complements.

D Latch — NOT gate ensures S=D, R=D̄ (no forbidden state)

LECTURE 21

Flip-Flops with Direct Inputs · Sequential Circuit Analysis

1. Direct (Asynchronous) Inputs: Preset (PRE) and Clear (CLR)
Direct inputs override the clock entirely — they act immediately regardless of the clock state. Also called asynchronous or override inputs.
  • Preset (PRE) / Set Direct (SD): Forces Q=1 immediately when active
  • Clear (CLR) / Reset Direct (RD): Forces Q=0 immediately when active
  • Typically active-LOW: PRE=0 activates preset; CLR=0 activates clear
  • When inactive (HIGH), normal clocked operation resumes
  • Priority: Direct inputs > Clock > Normal inputs
  • Used for power-on initialization, system reset
Never assert both PRE=0 and CLR=0 simultaneously! This is like the SR forbidden state — both Q and Q̄ would be forced HIGH. Final state unpredictable when both released.

LECTURES 23–24

Sequential Circuit Design · Excitation Tables · State-to-Circuit

1. Moore vs Mealy Machines
Moore Machine
Output depends ONLY on present state. Output changes are synchronous (change with state transitions).
  • Output assigned to states (circles in state diagram)
  • More states may be needed
  • More predictable — output glitch-free
  • State diagram: output written inside state circle
Moore: output=f(state)
Mealy Machine
Output depends on present state AND input. Output may change immediately when input changes.
  • Output assigned to transitions (arcs in state diagram)
  • Fewer states typically needed
  • Output may have glitches if input glitches
  • State diagram: arc labeled input/output
Mealy: output=f(state,input)

LECTURE 26

Registers — 4-bit Register with Parallel Load

1. What is a Register?
A register is a group of n flip-flops that stores an n-bit binary word. All FFs share the same clock.
  • n-bit register = n flip-flops (usually D type)
  • All FFs clocked simultaneously → data stored in parallel
  • Common operations: Load, Hold, Shift, Clear
  • Registers are the basic storage unit inside a CPU
  • A register file = array of registers (e.g., 32 registers in MIPS)
4-bit Register — 4 D Flip-Flops
2. 4-bit Register with Parallel Load — Complete Circuit

A parallel load register has a control input LD (Load). When LD=1, the register loads new 4-bit data on the clock edge. When LD=0, it holds its current value.

Implementation: Each D input is a 2:1 MUX: D_i = LD·I_i + L̄D·Q_i

1. Shift Register Concept & Types
A shift register moves data laterally — each clock edge shifts all bits one position left or right. The entering bit comes from a serial input; the exiting bit is the serial output.

SIPOSerialParallelSerial→parallel conversion

  • Serial arithmetic (serial adder)

5. Serial Adder Using Shift Register
A serial adder adds two n-bit numbers one bit at a time, using a single full adder and a carry flip-flop to store the carry between additions.
Serial Adder — Full Adder + Carry FF + Two Shift Registers
  • Start with carry FF = 0
  • Each clock pulse: adds LSBs of A and B plus carry → sum stored back into A, carry stored in carry FF
  • After n clock pulses: A contains the full sum
  • Takes n clock cycles for n-bit addition (slower but less hardware than parallel adder)

Microoperations & Counters: Ripple (Asynchronous) Counter

1. Microoperations & Register Transfer Language (RTL)
A microoperation is a basic operation on data in registers, performed in one clock cycle. Register Transfer Language (RTL) describes these operations symbolically.
RTL Notation
  • R2 ← R1 : Transfer R1 into R2
  • R1 ← R1 + R2 : Arithmetic add
  • R1 ← R1 ∧ R2 : Logic AND
  • R1 ← shl R1 : Shift left by 1
  • P: R2 ← R1 : Conditional (only if P=1)
  • if (P=1) then R2 ← R1 : Same
Classes of Microoperations
ClassOperations
TransferCopy, Move data
ArithmeticAdd, Sub, Increment, Decrement, Negate
LogicAND, OR, XOR, NOT, Shift
ShiftLeft shift, Right shift, Rotate
2. Counters — Introduction
A counter is a sequential circuit that cycles through a fixed sequence of states on successive clock pulses.
Asynchronous (Ripple) Counter
  • Flip-flops NOT clocked simultaneously
  • Q̄ output of each FF drives clock of next FF
  • Propagation delay accumulates: total delay = n × t_FF
  • Simpler to build but produces glitches
  • Also called ripple counter because carry ripples through stages
Synchronous Counter
  • All flip-flops clocked simultaneously
  • Combinational logic determines which FFs toggle
  • Total delay = one gate delay + one FF delay
  • No glitches; faster; more hardware

Synchronous Counters — BCD · Up/Down · Parallel Load

1. Why Synchronous Counters?
In a synchronous counter, ALL flip-flops are clocked by the same clock signal simultaneously. Combinational logic determines which FFs should toggle.
  • No ripple delay — all FFs change at same time
  • Maximum operating frequency is much higher
  • No momentary wrong states (no glitches)
  • Cost: more gates (carry logic between stages)

LECTURE 30

Memory — RAM, ROM, Organization, Chip Select, Memory Expansion

1. Memory Fundamentals
Memory stores binary data as an array of bits, organized into addressable locations. Address lines select which location to read or write.
Key Memory Parameters
  • Address space: k address bits → 2ᵏ locations
  • Word size: n data bits per location
  • Capacity: 2ᵏ × n bits total
  • Example: 16×8 memory = 16 locations × 8 bits each = 128 bits total; needs 4 address bits
  • Usually written as: 2ᵏ × n → "2^k by n" memory chip

2. Random Access Memory (RAM) — Types and Internal Structure
SRAM (Static RAM)
  • Each cell = 6 transistors (cross-coupled inverters + access transistors)
  • Holds data as long as power is on — no refresh needed
  • Very fast (used for CPU cache)
  • More expensive, larger cell, less dense
DRAM (Dynamic RAM)
  • Each cell = 1 transistor + 1 capacitor
  • Stores charge on capacitor — leaks away
  • Needs periodic refresh (every few ms)
  • Slower but much cheaper and denser
  • Used for main memory (DDR DRAM)

5. Memory Expansion — Increasing Word Length and Address Space
Word Length Expansion (Increase data bits)

Connect chips in parallel — same address goes to all chips, each provides some data bits.

Word Length Expansion: 2 chips of 4×4 → 4×8
Address Space Expansion (Increase locations)

Stack chips so only one is selected at a time using a decoder and chip select lines.

Address Space Expansion: Decoder selects chip; low-order addr bits select location within chip
